# Política de Segurança / Security Policy

Esta política vale para todos os repositórios de `{{OWNER}}` que não tenham um `SECURITY.md` próprio.
This policy applies to every `{{OWNER}}` repository without its own `SECURITY.md`.

## Versões suportadas / Supported versions

Só a última versão publicada de cada projeto recebe correções de segurança.
Only the latest released version of each project receives security fixes.

## Reportando uma vulnerabilidade / Reporting a vulnerability

Não abra uma issue pública. Use o *Report a vulnerability* do GitHub (*Security > Advisories*) no repositório afetado
ou escreva para **{{CONTACT_EMAIL}}**. Responderemos assim que possível e combinaremos a divulgação.

Do not open a public issue. Use GitHub's *Report a vulnerability* (*Security > Advisories*) on the affected repository
or write to **{{CONTACT_EMAIL}}**. We will reply as soon as possible and coordinate the disclosure.
